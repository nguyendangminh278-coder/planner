# Planner mascot asset

Generated using the built-in **image_gen** tool, using the character image supplied by the user as an identity reference. The image is a transparent PNG pose atlas consumed directly with CSS background positions; no raster cutting or background-removal postprocessing was used.

Layout: square 2 × 2 cells, in reading order: sitting/playing, running with pencil, writing a gray line, pulling a task. This is a set of 3D-style rendered sprites, rather than an interactive 3D model.

Final generation prompt:

> Use case: stylized-concept. Asset type: one production-ready transparent PNG character pose atlas for a website mascot, a square canvas arranged as EXACTLY a 2 by 2 grid of FOUR equal square cells. The supplied image is a CHARACTER IDENTITY REFERENCE, not an edit target. Create fresh polished soft 3D toy/clay renders of the same cheerful male chibi: very large round dark brown/olive eyes, warm skin, tousled black curtain hair, one tiny silver hoop earring, black casual jacket open over white T-shirt, black cropped trousers, beige sneakers. Keep face, hairstyle, clothing, proportions and lighting consistent in all four cells. Every cell has exactly ONE full-body character, same scale, centered, entirely inside that cell with at least 10 percent transparent margin. Row 1 column 1: seated cross-legged at rest, smiling, casually playing with his original microphone, front three-quarter view. Row 1 column 2: running to the right, lively mid-stride, right-facing three-quarter view, holding a gray pencil. Row 2 column 1: kneeling/crouching, facing right, extending right arm with a long gray pencil to draw a horizontal line to the right at chest height, friendly focused face, clear visible pencil tip. Row 2 column 2: standing and leaning backwards toward the right, both arms extended left as if firmly grabbing and pulling the edge of a task card offscreen; DO NOT render the card itself, just the gripping/pulling pose. Genuine transparent alpha background in every cell; no opaque ground plane, no scenery, only a very soft translucent contact shadow directly under feet. No grid lines, no labels, no text, no logos or watermarks. Soft studio light, rounded 3D geometry and detailed hair strands like the reference. Exact 2x2 cell layout and no overlap are critical for CSS sprite rendering.

Animation reference: [Web Animations API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Animations_API/Using_the_Web_Animations_API), [reduced motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion).
